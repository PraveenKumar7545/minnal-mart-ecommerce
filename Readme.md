# 🛒 MinnalMart - Electronics E-Commerce Website

A modern and responsive **multi-page electronics e-commerce website** built using **HTML5 and Tailwind CSS**.

MinnalMart provides a clean and user-friendly shopping interface with multiple product categories, product listings, offers, cart, wishlist, login, customer support, and other essential e-commerce pages.

---

## 🚀 Live Demo

🌐 **[View MinnalMart Live Website](https://praveenkumar7545.github.io/minnal-mart-ecommerce/Front_End_Project/Minnal_mart/login.html)**

---

## 📌 Project Overview

**MinnalMart** is a frontend e-commerce project developed to practice and demonstrate modern web design using **HTML5 and Tailwind CSS**.

The project contains **17 individual pages** connected through a common navigation system.

The website focuses on:

* 📱 Responsive web design
* 🎨 Modern and clean UI design
* ⚡ Tailwind CSS utility classes
* 🔗 Multi-page navigation
* 🛍️ Product category organization
* 🛒 E-commerce page layouts
* ✨ Interactive hover effects
* 📱 Responsive navigation
* ♻️ Reusable design patterns
* 🎁 Offers and promotional sections
* ❤️ Wishlist and shopping cart interface

## 🎯 Project Goals

The main goals of this project are:

* To build a complete multi-page e-commerce frontend.
* To practice HTML5 page structuring.
* To understand and implement Tailwind CSS.
* To create responsive layouts for different screen sizes.
* To design reusable e-commerce components.
* To improve frontend development and UI/UX skills.
* To understand navigation between multiple web pages.
